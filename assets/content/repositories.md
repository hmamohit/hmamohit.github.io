## Featured Repositories

### EmbedTAD
Graph embedding and unsupervised learning framework for identifying TADs from high-resolution Hi-C data.  
[Open Repository](https://github.com/OluwadareLab/EmbedTAD)

### HiCForecast
Dynamic optical-flow-inspired model for forecasting spatiotemporal Hi-C contact maps.  
[Open Repository](https://github.com/OluwadareLab/HiCForecast)

### ScHiCAtt
Attention-based enhancement pipeline for sparse single-cell Hi-C data resolution.  
[Open Repository](https://github.com/OluwadareLab/ScHiCAtt)

### coiTAD
TAD detection using clustering over circular influence feature representations from Hi-C matrices.  
[Open Repository](https://github.com/OluwadareLab/coiTAD)

### CNNSplice
Convolutional neural network models for robust splice site prediction across organisms.  
[Open Repository](https://github.com/OluwadareLab/CNNSplice)

### Loop Caller Benchmark
Comparative benchmark resources for evaluating chromatin loop caller outputs and overlap quality.  
[Open Repository](https://github.com/OluwadareLab/Comprehensive_Loop-Caller_Benchmark)
