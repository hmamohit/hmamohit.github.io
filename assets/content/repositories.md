## Featured Repositories

### HiCInterpolate
Deep learning framework for 4D spatiotemporal interpolation of Hi-C contact matrices, predicting intermediate genome architecture from sparse temporal observations.
**Tag:** Time-Series, Interpolation, CV, Flow, Hi-C
[Open Repository](https://github.com/OluwadareLab/HiCInterpolate)

### EmbedTAD
Unsupervised TAD detection framework integrating graph embedding (NetMF) and density-based clustering (HDBSCAN) for high-resolution Hi-C data.
**Tag:** Graph, Embedding, Clustering, Hi-C, TAD
[Open Repository](https://github.com/OluwadareLab/EmbedTAD)

### Robin
Containerized Flask web application integrating large language models for comparative loop caller analysis, interactive HiGlass visualization, and LLM-assisted figure generation.
**Tag:** LLM, Web Application, Flask, Docker, Hi-C
[Open Repository](https://github.com/OluwadareLab/Robin)

### HiCForecast
Deep learning framework using dynamic network optical flow to forecast future spatiotemporal Hi-C contact maps across biological systems.
**Tag:** Time-Series, Forecasting, CV, Flow, Hi-C
[Open Repository](https://github.com/OluwadareLab/HiCForecast)

### ScHiCAtt
Attention-based deep learning framework to enhance the resolution of single-cell Hi-C contact maps and resolve chromatin interaction sparsity.
**Tag:** Attention, Single-Cell, Super-Resolution, Hi-C
[Open Repository](https://github.com/OluwadareLab/ScHiCAtt)

### Loop Caller Benchmark
Comprehensive benchmarking framework evaluating 22 chromatin loop callers across simulated and experimental Hi-C datasets with the task-specific BCCscore metric.
**Tag:** Benchmark, Tool Evaluation, Python, Shell
[Open Repository](https://github.com/OluwadareLab/Comprehensive_Loop-Caller_Benchmark)

### coiTAD
Computational framework for identifying Topologically Associating Domains from Hi-C contact maps using circular influence features and HDBSCAN clustering.
**Tag:** HDBSCAN, Clustering, TAD Detection, Hi-C
[Open Repository](https://github.com/OluwadareLab/coiTAD)

### CNNSplice
Convolutional neural network models for splice-site prediction across five organisms with deployable inference workflows in PyTorch, Flask, and Docker.
**Tag:** Deep Learning, CNN, Splice Site, Docker, Flask
[Open Repository](https://github.com/OluwadareLab/CNNSplice)
