## Selected Research Projects

### HiCInterpolate
- Python, PyTorch, Spatiotemporal DL — Developed a 4D deep learning method to interpolate intermediate Hi-C maps from two timepoints at 10Kb resolution; evaluated using PSNR, SSIM, GenomeDISCO, and HiCRep.
- [GitHub Repository](https://github.com/OluwadareLab/HiCInterpolate)

### EmbedTAD
- Python, Graph Embedding, Unsupervised Learning — Developed the first unsupervised graph-embedding-based TAD caller; achieved the highest statistical scores among 7 callers across 5 noise levels.
- [GitHub Repository](https://github.com/OluwadareLab/EmbedTAD)

### Robin
- Python, Flask, Docker, LLM — Built a deployable web application for comparative chromatin loop-caller analysis, interactive HiGlass visualization, and LLM-assisted natural language figure generation.
- [GitHub Repository](https://github.com/OluwadareLab/Robin)

### HiCForecast
- Python, PyTorch, Optical Flow — Built a deep learning pipeline using dynamic network optical flow to predict future chromatin contact maps, outperforming HiC4D across GenomeDISCO, PCC, SSIM, and PSNR.
- [GitHub Repository](https://github.com/OluwadareLab/HiCForecast)

### Chromatin Loop-Caller Benchmark
- Python, Statistical Analysis — Benchmarked 22 chromatin loop callers across simulated and experimental Hi-C datasets, introducing the task-specific BCCscore metric for systematic tool selection.
- [GitHub Repository](https://github.com/OluwadareLab/Comprehensive_Loop-Caller_Benchmark)

### ScHiCAtt
- Python, Attention Mechanisms, scHi-C — Developed an attention-based deep learning framework to enhance the resolution of single-cell Hi-C contact maps and mitigate data sparsity.
- [GitHub Repository](https://github.com/OluwadareLab/ScHiCAtt)

### CNNSplice
- Python, PyTorch, Flask, Docker — Built CNN-based splice-site predictors across 5 organisms, achieving up to ~97% accuracy; deployed via Flask and Docker.
- [GitHub Repository](https://github.com/OluwadareLab/CNNSplice)

### coiTAD
- MATLAB/Python, Hi-C Analysis — Developed a TAD detection framework using circular influence features from Hi-C contact matrices clustered with HDBSCAN.
- [GitHub Repository](https://github.com/OluwadareLab/coiTAD)
